void TaskAnalyzerReader ( void * pv)

Main task to handle SPI slave communication with the Analyzer Master.

ANALYZER_READER_TX_SIZE.

This implementation uses the Half-Duplex (HD) SPI slave driver to correctly handle the Master's command-response protocol. It receives a command and argument, then sends the appropriate data back in the same transaction.
